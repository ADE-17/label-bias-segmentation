# Label Bias in Segmentation: Detection and Mitigation

Anonymous code release accompanying the paper submission. This repository contains the
training, mitigation, and evaluation pipeline used for all experiments, together with the
exact cross-validation splits, per-experiment configuration files, and random seeds.

## Overview

We study *group-dependent annotation bias* in binary segmentation: one demographic group
receives systematically shifted labels (e.g. eroded masks, coarser annotators) while the other
group receives clean labels. The pipeline

1. injects controlled label bias into a training set at a chosen bias ratio,
2. trains ERM baselines and mitigation methods (fairness regularisers, adversarial, MMD/CORAL,
   noise-robust losses, and the proposed asymmetric loss / style-conditioned FiLM decoder),
3. audits the observed training labels with Confident Learning to measure Label Error Rate (LER)
   and Signed Directional Rate (SDR) per group, and evaluates IoU against clean and observed
   test labels.

## Datasets

| Key          | Dataset                    | Groups                           | Bias source                                          |
|--------------|----------------------------|----------------------------------|------------------------------------------------------|
| `celebamask` | CelebAMask-HQ (30k faces)  | gender attribute                 | synthetic erosion / dilation / wave of the mask       |
| `phc`        | PhC-U373 cells (651 imgs)  | synthetic colour tint (2 groups) | fine (clean) vs. coarse (biased) human annotators     |
| `imapp`      | IMA++ dermoscopy (590 imgs)| estimated skin tone (ITA)        | consensus (clean) vs. lower-skill annotator (biased)  |

Datasets are not redistributed. Set `--data_root` (or edit `DATASET_DEFAULTS` in
`dataset_factory.py`) to your local copies. Placeholder paths in the code are `/path/to/...`.

## Reproducibility: splits, seeds, and configs

* **Splits.** `configs/splits/{cv_splits,phc_splits,imapp_splits}.json` hold the 15 % held-out
  test set and the 5 stratified folds for each dataset. All were generated by
  `utils/splits.py` with `random_seed=42`, `test_ratio=0.15`, stratified by group.
* **Seeds.** Every training script uses `--seed 42` (model init, shuffling) and
  `--bias_seed 42` (selection of which samples in the target group receive biased labels).
  Batch scripts also export `PYTHONHASHSEED=42`. Per-sample augmentation of biased masks is
  derived deterministically from `bias_seed` and the sample index.
* **Experiment configs.** `configs/experiments/<exp_name>/fold_<k>.json` are the exact
  argument dumps written at training time for each fold, including the resolved bias
  configuration (number of biased samples, biased group, erosion radius, etc.).
* **Dataset CSVs.** `configs/imapp_processed.csv` maps each IMA++ image to its clean and
  biased mask and skin-tone group. `configs/ita_stats_kmeans.csv` holds the estimated ITA and
  skin-tone category per ISIC-2017 image used to build it (paths are placeholders).

## Setup

```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
```

Tested with Python 3.10, PyTorch 2.x, `segmentation-models-pytorch` (U-Net with ResNet-34 or
MiT-B2 encoders).

## Running

Train the full mitigation suite on CelebAMask-HQ for one fold and one bias ratio:

```bash
FOLD=0; BIAS=0.50; EPOCHS=15
python train_biased.py      --dataset celebamask --bias_mode erosion --bias_ratio $BIAS --erosion_radius 15 --epochs $EPOCHS --fold $FOLD --exp_name celeba_baseline_r$BIAS
python train_biased.py      --dataset celebamask --bias_mode erosion --bias_ratio $BIAS --erosion_radius 15 --loss_mode gce_dice --epochs $EPOCHS --fold $FOLD --exp_name celeba_gce_r$BIAS
python train_debiased.py    --dataset celebamask --method fairness --fairness_mode eo --bias_ratio $BIAS --erosion_radius 15 --epochs $EPOCHS --fold $FOLD --exp_name celeba_eo_r$BIAS
python train_debiased.py    --dataset celebamask --method adversarial --lambda_debias 0.01 --bias_ratio $BIAS --erosion_radius 15 --epochs $EPOCHS --fold $FOLD --exp_name celeba_adv_r$BIAS
python train_debiased.py    --dataset celebamask --method domain_invariant --domain_method coral --lambda_debias 0.01 --bias_ratio $BIAS --erosion_radius 15 --epochs $EPOCHS --fold $FOLD --exp_name celeba_coral_r$BIAS
python train_debias_asym.py --dataset celebamask --method asym_style --bias_ratio $BIAS --erosion_radius 15 --epochs $EPOCHS --fold $FOLD --exp_name celeba_asym_style_r$BIAS
```

Evaluate (IoU on clean/observed test labels plus the Confident Learning audit of the training labels):

```bash
python evaluate_experiments.py --dataset celebamask \
    --experiments_dir /path/to/output/experiments \
    --experiments celeba_baseline_r0.50 celeba_asym_style_r0.50 \
    --output_dir /path/to/output/evaluations
```

`scripts/` contains the complete SLURM job files used for every table in the paper
(CelebAMask-HQ mitigations at 25/50/75/100 % bias, PhC-U373 at 100 %, IMA++ at 0/50 %,
encoder and 0 %-bias ablations). Adjust the `#SBATCH` header, venv path, and data paths.

## Outputs

Each run writes `experiments/<exp_name>/fold_<k>/` with `config.json`, `best_model.pt`,
training history, and test metrics. Evaluation writes `all_experiments_summary.csv`
with per-experiment IoU (clean / observed, per group and gap), LER, SDR, and excess/deficit
pixel counts per group, which `tables/` formats into LaTeX.
