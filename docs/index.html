1 Label bias in segmentation

Two groups, two annotation styles

Images of group gc are annotated carefully, with tight boundaries. Images of group gb are annotated by someone who constantly over-segments. Each mask is mostly right, but the error is systematic and tied to the group. That is label bias.

Because pixels have geometry, bias has a direction. The paper studies three: under-segmentation (deficit, e.g. erosion), over-segmentation (excess, e.g. dilation or coarse "bloated" masks) and wavy boundary distortion (mixed).

2 The bent ruler

Observed performance does not track true performance

Fairness audits compare IoU across groups, computed against the observed labels, the very labels that are biased. A model that reproduces the biased style scores well on the biased test set. The true disparity, visible only with clean labels, can be far larger, far smaller, or move the other way.

Subgroup IoU gap vs. amount of label bias

Takeaway. Evaluation against observed labels hides label bias rather than detecting it. We need an audit signal that does not require clean labels.
3 Confident Learning as an audit

Confident predictions as a second opinion

A model trained with cross-fitting on the biased data is still confident on most pixels, because it has seen many images and most of each mask is correct. Where a confident prediction disagrees with the observed label, we flag a suspected label error and split it by direction.

How the audit works on one image

animation

LER

Label Error Rate: (excess + deficit) / foreground. How much suspected error.

DR

Directional Rate: (excess − deficit) / foreground. Which way: positive is over-, negative is under-segmentation.

RR

Relative Risk: LERgb / LERgc. Where errors concentrate; RR ≫ 1 flags a group.

What it means

From training data alone we get a proxy audit: how much label error there is, in which group, and in which direction. Thresholds adapt to the model's calibration, so temperature scaling leaves the gaps unchanged, and a retrospective check against clean masks confirms that detected errors track the injected bias.

Limitations

CL sees disagreement, not truth. If the biased style dominates (β = 100 % erosion on CelebAMask-HQ) the model absorbs it and the audit under-reports (the ⚠ markers). It needs a competent segmenter, and deciding which group's style is "right" still needs domain knowledge.

4 Subgroup separability

Biased labels teach the encoder to tell the groups apart

To fit two annotation styles with one decoder, the network must know which style to produce, so it learns the group. In the encoder's latent space, gc and gb drift apart as the bias grows, well beyond what visual differences cause.

Separability is a symptom, not the disease. Group information in the representation is not itself the fairness problem here; the biased labels are. Methods that erase group information (adversarial, MMD, CORAL) leave the true gap untouched in our experiments, because the labels are still wrong. We make this argument in full in our follow-up preprint Is invariance all you need for algorithmic fairness? Removing demographic information can create new bias: enforcing demographic invariance can hamper mitigation and even create new bias. Here we use the group signal instead of suppressing it.
5 Mitigation

Learn every style, then predict in the cleanest one

The Subgroup-Conditioned Decoder (SCD) feeds a group code into the decoder through FiLM layers, so each annotation style gets its own feature modulation. At inference, every image is decoded with the reference code, and the biased style never leaves training. Auto-SCD removes the need to know the cleaner group: after a few warm-up epochs the group with lower training loss is chosen, because clean labels are easier to fit.
