Label bias in segmentation

Two groups, two annotation styles

  • gc is annotated with tight, detailed boundaries.
  • gb is annotated by someone who constantly over-segments.
  • Same objects, same difficulty. Only the style differs, and it is tied to the group.

  • Pixels have geometry, so bias has a direction: deficit (under-segmentation), excess (over-segmentation), or irregular (both).

The bent ruler

Observed performance does not track true performance

  • IoU is computed against the observed labels, which are the biased ones.
  • The true subgroup gap, visible only with clean labels, can be far larger, smaller, or move the other way.

Confident Learning as an audit

Audit the training labels with the training set itself

  • No clean labels. Everything below uses only the biased training set and a model trained on it.
  • Cross-fitting. Split the training set into K folds; each fold is predicted by a model that never saw it.
  • Confident joint Q. Count confident pixels in a 2×2 matrix of observed label vs. predicted label. Only the off-diagonal cells are suspected label errors.
  • Direction. Excess (label 1, model 0) and deficit (label 0, model 1) are summed into LER, subtracted into DR, and compared across groups as RR.

What it gives

  • How much error (LER), which way (DR), in which group (RR).
  • Thresholds adapt to calibration; temperature scaling leaves the gaps unchanged.
  • Validated retrospectively against clean masks.

Limits

  • Measures disagreement, not truth: when the biased style dominates (β = 100 % erosion) the model absorbs it and the audit under-reports.
  • Needs a competent segmenter.
  • Which style is "right" is still a domain decision.
Subgroup separability

Biased labels teach the encoder to tell the groups apart

  • To fit two styles with one decoder, the network has to know the group, so it learns it.
  • In the encoder's latent space gc and gb drift apart as bias grows: silhouette ×3.9, Fisher ratio ×8.8 from unbiased to fully biased.
Separability is a symptom, not the fairness problem. Erasing group information (adversarial, MMD, CORAL) leaves the true gap untouched because the labels are still wrong. See our follow-up preprint: Is invariance all you need for algorithmic fairness? Removing demographic information can create new bias. Here we use the group signal instead of suppressing it.
Mitigation

Learn every style, predict in the cleanest one

  • SCD. A group code enters the decoder through FiLM layers; each annotation style gets its own modulation. At inference every image is decoded with the reference code.
  • Auto-SCD. Track the training loss per group during warm-up and pick the group with the lowest loss as reference. Clean labels are easier to fit.
